# vendor-performance-analysis

## Project Overview
This project focuses on analyzing vendor performance using SQL, Python, and Power BI. The objective is to evaluate vendor sales, purchasing patterns, profitability, and inventory turnover to identify business insights and opportunities for improvement.

## Objectives
- Analyze vendor-wise sales and purchase performance.
- Evaluate profitability and vendor contribution to overall sales.
- Investigate the relationship between bulk purchasing and unit purchase prices.
- Identify inventory turnover patterns and potential slow-moving inventory.
- Present key performance metrics through data visualization and reporting.

## Tools & Technologies
- **SQL:** Data extraction, joins, aggregations, and vendor-level analysis.
- **Python:** Data processing, exploratory data analysis (EDA), and visualization.
- **Pandas:** Data manipulation and summary analysis.
- **Matplotlib:** Charts and data visualization.
- **Power BI:** Dashboard development and business reporting.

## Project Workflow
1. Data ingestion and database preparation.
2. Data exploration and consolidation using SQL.
3. Vendor-level sales and purchase analysis.
4. Exploratory data analysis and visualization using Python.
5. Analysis of profitability, purchasing patterns, and inventory turnover.
6. Power BI dashboard development for presenting business insights.

## Key Areas of Analysis
- Vendor sales performance and contribution.
- Purchase prices and bulk purchasing patterns.
- Sales and profit trends across brands and vendors.
- Vendor profit margins.
- Inventory turnover and slow-moving inventory.
- Relationships between numerical business metrics.

## Business Value
The analysis helps identify high-performing vendors, investigate profitability differences, and highlight potential opportunities to improve purchasing decisions and inventory efficiency.

## Repository Structure
The repository will contain SQL queries, Python analysis files, dashboard assets, and supporting documentation as they are added.
